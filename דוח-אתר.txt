1. שם האתר
MP-BusinessCards-Pro
שם תצוגה באתר: Business Cards
תיאור: מערכת לניהול כרטיסי ביקור דיגיטליים עם משתמשים, הרשאות, JWT, וכרטיסי עסק.

2. על מה האתר בנוי
Backend:
- Node.js + Express.js
- MongoDB + Mongoose
- JWT לצורך אימות משתמשים
- bcryptjs להצפנת סיסמאות
- Joi לוולידציה
- morgan ו-File Logger ללוגים
- cors ו-config לניהול תצורה

Frontend:
- קובץ HTML סטטי: index.html
- CSS סטטי: public/styles.css
- JavaScript בתוך index.html עבור התחברות, טעינת כרטיסים וקריאות API

פריסה:
- מקומי: server.js מאזין לפורט מתוך config.
- Production מקומי בבדיקה: http://localhost:9191
- Development לפי README: http://localhost:8181
- Vercel: api/index.js + vercel.json, כל הנתיבים מנותבים לפונקציית Express.

פקודות שנבדקו:
- node -v: v22.22.0
- npm -v: 10.9.2
- npm run build: עבר בהצלחה.

הערות תצורה:
- package.json מגדיר engines: Node 24.x.
- README מציין דרישת Node.js 18.x.
- בפועל הסריקה רצה עם Node v22.22.0 וה-Build עבר.

3. מה בדיוק לא עובד
האתר עצמו עולה והדף הראשי מחזיר תקין, אבל פעולות שתלויות במסד הנתונים לא עובדות כרגע בגלל חוסר חיבור ל-MongoDB.

מה עובד:
- npm run build עבר בהצלחה.
- הדף הראשי / מחזיר HTTP 200.
- title של הדף: Business Cards.
- /api/health מחזיר HTTP 200 ומראה שהשרת רץ.
- /api/cards מחזיר HTTP 200, אבל מחזיר מערך ריק [] כי אין חיבור למסד.

מה לא עובד:
- התחברות משתמשים לא עובדת כי מסד הנתונים לא מחובר.
- יצירת משתמשים/כרטיסים, עדכון, מחיקה, לייקים, והרשאות בפועל לא יעבדו בלי MongoDB מחובר.
- נתוני initialData לא נטענים למסד כי אין חיבור למסד.
- Google OAuth לא פעיל, והכפתור ב-index.html מוגדר disabled.

בעיה נוספת שנמצאה:
- קיימת פונקציית validateRuntimeEnv ב-utils/validateEnv.js שבודקת משתני סביבה חסרים, אבל לא נמצאה קריאה אליה בזמן עליית השרת. לכן השרת עולה גם כשחסרים משתני MongoDB/JWT, ורק אחר כך פונקציות מסוימות מחזירות שגיאות.

4. איפה הבעיה קורית
הבעיה המרכזית קורית בחיבור למסד הנתונים:
- Production: DB/mongoDB/connectToAtlasDb.js

- משתני סביבה נדרשים: .env.example, config/production.json, config/custom-environment-variables.json

נקודות API שנפגעות:

- POST /api/users
- GET /api/users
- PUT /api/users/:id
- DELETE /api/users/:id
- POST /api/cards
- PUT /api/cards/:id
- PATCH /api/cards/:id
- DELETE /api/cards/:id
- חלק מהקריאות GET מחזירות מערך ריק במקום נתונים כשאין DB.

מיקום בקוד:
- users/models/usersAccessDataService.js מחזיר Database is currently unavailable כאשר אין חיבור.
- cards/models/cardsDataAccessService.js מחזיר Database is currently unavailable בפעולות כתיבה ועדכון.
- cards/models/cardsDataAccessService.js מחזיר [] עבור רשימת כרטיסים כאשר אין חיבור.
- server.js מפעיל את החיבור למסד ואת initialData.

פעולות תיקון מומלצות:
- ליצור קובץ .env.production או להגדיר ב-Vercel Environment Variables:
  - NODE_ENV=production
  - PORT=9191 או לפי סביבת ההרצה
  - DB=MONGODB
  - JWT_KEY או JWT_SECRET
  - MONGODB_URI או DB_NAME + DB_PASSWORD + MONGODB_CLUSTER_HOST
- לפיתוח מקומי ליצור .env.development או להריץ MongoDB מקומי בכתובת:
  mongodb://localhost:27017/business_card_app
- לקרוא ל-validateRuntimeEnv בזמן עליית השרת כדי לעצור מוקדם עם הודעה ברורה כשחסר ENV קריטי.
- ליישר גרסאות Node בתיעוד: package.json דורש 24.x, README מציין 18.x.
